# homebrew-mctui

Homebrew tap for [mctui](https://github.com/VeeB0/mctui) — a terminal UI for Minecraft servers.
Installs prebuilt binaries for macOS (Apple Silicon / Intel) and Linux (x86_64 / arm64).

## Install

```bash
brew install VeeB0/mctui/mctui
```

## Upgrade

```bash
brew upgrade mctui
```

Do not use `mctui update` for a Homebrew install: Homebrew manages the binary, so upgrade with `brew upgrade mctui`.

The formula is updated automatically by the mctui release workflow on every new release.

# homebrew-mctui (по-русски)

Homebrew-репозиторий для [mctui](https://github.com/VeeB0/mctui) — TUI для серверов Minecraft.
Ставит готовые бинарники для macOS (Apple Silicon / Intel) и Linux (x86_64 / arm64).

## Установка

```bash
brew install VeeB0/mctui/mctui
```

## Обновление

```bash
brew upgrade mctui
```

Не используйте `mctui update`, если программа установлена через Homebrew: бинарником управляет brew,
обновляйте через `brew upgrade mctui`.

Формула обновляется автоматически при каждом новом релизе mctui.
